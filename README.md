# 🚀 Multi-Level Machine Learning Projects Portfolio

This repository contains end-to-end Machine Learning implementations ranging from classification and time-series forecasting to industrial anomaly detection.

---

## 📌 Projects Breakdown

### 1. Level 2: Loan Approval Prediction (Classification)
* **Goal:** Automate credit risk assessment and predict loan approvals using demographic and financial indicators.
* **Algorithm:** Random Forest Classifier
* **Insights:** CIBIL score, applicant income, and loan amount proved to be the most critical features influencing credit approval decisions.

## 🛠️ Tools & Technologies Used
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn (RandomForest, LabelEncoder, StandardScaler)
* **Environment:** Google Colab
